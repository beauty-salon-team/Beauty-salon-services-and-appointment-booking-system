## ۱. مقدمه

### ۱.۱ هدف سند
این سند پرسوناهای کاربران هدف پروژهٔ **سیستم سالن زیبایی** را تعریف می‌کند. هدف آن ایجاد درک عمیق از نیازها، اهداف و دردهای کاربران است.

### ۱.۲ چرا پرسونا؟
پرسونا یک **نمایندهٔ فرضی** از یک گروه کاربری است. کمک می‌کند:
- تیم توسعه بداند برای **چه کسی** می‌سازد.
- از «طراحی برای همه» پرهیز شود.
- اولویت‌بندی ویژگی‌ها بر پایهٔ نیاز واقعی باشد.

### ۱.۳ روش‌شناسی
- مصاحبهٔ فرضی با مشتری
- مشاهدهٔ رفتار رزرو نوبت
- مطالعهٔ سایت‌های مشابه
- تجربهٔ شخصی

## ۲. پرسونا ۱ — خانم رضایی (ادمین)

### مشخصات دموگرافیک
| ویژگی | مقدار |
|--------|-------|
| نام | فاطمه رضایی |
| سن | ۴۵ سال |
| جنسیت | زن |
| شغل | صاحب و مدیر سالن زیبایی |
| محل زندگی | تهران |
| تحصیلات | دیپلم |
| مهارت فنی | متوسط |
| وضعیت تأهل | متأهل |

### نقل‌قول
> «مدیریت نوبت‌ها با دفتر و خودکار خیلی سخته. بعضی وقت‌ها نوبت‌ها با هم تداخل پیدا می‌کنن.»

### اهداف
- حذف فرآیندهای دستی ثبت نوبت
- جلوگیری از تداخل زمانی
- افزایش مشتریان از طریق آنلاین

### دردها
- ثبت نوبت تلفنی و پراکنده
- پیدا کردن زمان خالی متخصصین
- فراموشی نوبت توسط مشتری

### نیازها
- پنل ادمین ساده
- مشاهدهٔ لیست نوبت‌ها
- تنظیم ساعات کاری

### سناریوی استفاده
> صبح با لپ‌تاپ وارد پنل ادمین می‌شود. نوبت‌های امروز را می‌بیند. یک خدمت جدید اضافه می‌کند و ساعات کاری متخصص جدید را تنظیم می‌کند.

## ۳. پرسونا ۲ — سارا (مشتری نهایی)

### مشخصات دموگرافیک
| ویژگی | مقدار |
|--------|-------|
| نام | سارا محمدی |
| سن | ۲۸ سال |
| جنسیت | زن |
| شغل | کارمند |
| محل زندگی | تهران |
| تحصیلات | کارشناسی |
| مهارت فنی | بالا |
| وضعیت تأهل | مجرد |

### نقل‌قول
> «بعد از ساعت کاری وقت ندارم برم سالن و تو صف بشینم. دوست دارم از خونه نوبت بگیرم.»

### اهداف
- رزرو نوبت در هر ساعت
- مشاهدهٔ شفاف قیمت‌ها
- جلوگیری از اتلاف وقت

### دردها
- تماس تلفنی در ساعات شلوغی
- عدم اطلاع از زمان‌های خالی
- پراکندگی اطلاعات قیمت‌ها

### نیازها
- جست‌وجوی خدمات
- تقویم زمان‌های خالی
- رزرو آنلاین
- لغو نوبت بدون تماس

### سناریوی استفاده
> شب با موبایل وارد سایت می‌شود. خدمات را می‌بیند. برای «رنگ مو» متخصص مریم را انتخاب می‌کند. ساعت ۵ عصر فردا را رزرو می‌کند.

## ۴. پرسونا ۳ — مریم (متخصص زیبایی)

### مشخصات دموگرافیک
| ویژگی | مقدار |
|--------|-------|
| نام | مریم کاظمی |
| سن | ۳۲ سال |
| جنسیت | زن |
| شغل | متخصص رنگ و کوتاهی مو |
| محل زندگی | تهران |
| تحصیلات | فوق دیپلم |
| مهارت فنی | متوسط |
| وضعیت تأهل | متأهل |

### نقل‌قول
> «دوست دارم برنامهٔ روزانه‌ام رو از قبل بدونم تا بتونم زمان‌هام رو مدیریت کنم.»

### اهداف
- مشاهدهٔ دقیق برنامهٔ کاری
- اطلاع از نوبت‌ها
- جلوگیری از تداخل

### دردها
- برنامهٔ روزانه مشخص نیست
- تداخل نوبت‌ها
- اطلاع‌رسانی دیرهنگام

### نیازها
- مشاهدهٔ لیست نوبت‌های امروز
- اطلاع از ساعات کاری
- علامت زدن نوبت‌های انجام‌شده

### سناریوی استفاده
> صبح وارد پنل متخصص می‌شود. لیست نوبت‌های امروز را می‌بیند. بعد از هر نوبت، آن را «انجام‌شده» علامت می‌زند.
