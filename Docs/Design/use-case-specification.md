# Use Case Specification — سیستم سالن زیبایی

## UC-01: مدیریت حساب کاربری (User Management)

| بخش | توضیح |
|------|-------|
| **Actor (بازیگر)** | مشتری، مدیر (ادمین) |
| **پیش‌شرط (Precondition)** | کاربر وارد صفحه ثبت‌نام یا ورود شده است. |
| **جریان اصلی (Main Flow)** | ۱. کاربر اطلاعات (نام، شماره موبایل، رمز عبور) را وارد می‌کند.<br>۲. سیستم اطلاعات را اعتبارسنجی می‌کند.<br>۳. سیستم اطلاعات را در دیتابیس ذخیره می‌کند.<br>۴. پیام موفقیت نمایش داده می‌شود. |
| **جریان جایگزین (Alternative)** | اگر شماره موبایل تکراری باشد، پیام خطا نمایش داده می‌شود. |
| **User Storyهای مرتبط** | US-01 (ثبت‌نام و ورود) |

## UC-02: مدیریت و مشاهده خدمات (Service Management)

| بخش | توضیح |
|------|-------|
| **Actor (بازیگر)** | مشتری، مدیر (ادمین) |
| **پیش‌شرط (Precondition)** | کاربر وارد سیستم شده است. |
| **جریان اصلی (Main Flow)** | ۱. مشتری وارد صفحه خدمات می‌شود.<br>۲. سیستم لیست خدمات را از دیتابیس می‌خواند.<br>۳. لیست خدمات و قیمت‌ها نمایش داده می‌شود.<br>۴. ادمین می‌تواند خدمت جدید اضافه یا ویرایش کند. |
| **جریان جایگزین (Alternative)** | اگر لیست خدمات خالی باشد، پیام «خدماتی یافت نشد» نمایش داده می‌شود. |
| **User Storyهای مرتبط** | US-02 (مشاهده خدمات)، US-08 (مدیریت خدمات) |

## UC-03: مدیریت و رزرو نوبت (Appointment Management)

| بخش | توضیح |
|------|-------|
| **Actor (بازیگر)** | مشتری، متخصص، مدیر (ادمین) |
| **پیش‌شرط (Precondition)** | مشتری وارد سیستم شده است. |
| **جریان اصلی (Main Flow)** | ۱. مشتری خدمت و متخصص را انتخاب می‌کند.<br>۲. سیستم زمان‌های خالی را نمایش می‌دهد.<br>۳. مشتری زمان را انتخاب و رزرو می‌کند.<br>۴. سیستم نوبت را در دیتابیس ثبت می‌کند.<br>۵. پیام موفقیت و کد رهگیری نمایش داده می‌شود. |
| **جریان جایگزین (Alternative)** | اگر زمان انتخاب شده قبلاً رزرو شده باشد، پیام خطا نمایش داده می‌شود. |
| **User Storyهای مرتبط** | US-03, US-04, US-05, US-06, US-07, US-09 |

UC-04: تأییدیه رزرو نوبت (Appointment Confirmation)






بخش


 

توضیح


 




Actor (بازیگر)


 

مشتری


 




پیش‌شرط (Precondition)


 

مشتری مراحل رزرو نوبت را انجام داده است.


 




جریان اصلی (Main Flow)


 

۱. مشتری خدمت، متخصص و زمان موردنظر را انتخاب می‌کند. ۲. سیستم اطلاعات رزرو را بررسی می‌کند. ۳. در صورت موفقیت، نوبت ثبت می‌شود. ۴. سیستم پیام تأیید رزرو را به مشتری نمایش می‌دهد.


 




جریان جایگزین (Alternative)


 

اگر رزرو با موفقیت انجام نشود، سیستم پیام مناسب نمایش می‌دهد و از ثبت موفقیت‌آمیز نوبت خبر نمی‌دهد.
