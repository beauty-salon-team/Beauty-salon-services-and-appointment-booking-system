# Use Cases اصلی سیستم (System Use Cases)
این سند شامل Use Caseهای اصلی (قابلیت‌های سطح بالا) سیستم سالن زیبایی است.

### UC-01: مدیریت حساب کاربری (User Management)
*   **Actor (بازیگر):** مشتری، مدیر (ادمین)
*   **توضیحات:** فرآیند ثبت‌نام، ورود، خروج و مدیریت اطلاعات پروفایل کاربران سیستم.
*   **شامل User Storyهای:** US-01 (ثبت‌نام و ورود)

### UC-02: مدیریت و مشاهده خدمات (Service Management)
*   **Actor (بازیگر):** مشتری، مدیر (ادمین)
*   **توضیحات:** مشتریان می‌توانند لیست خدمات و قیمت‌ها را مشاهده کنند. مدیر سالن می‌تواند خدمات جدید اضافه کند یا قیمت‌ها را ویرایش کند.
*   **شامل User Storyهای:** US-02 (مشاهده خدمات)، US-08 (مدیریت خدمات)

### UC-03: مدیریت و رزرو نوبت (Appointment Management)
*   **Actor (بازیگر):** مشتری، متخصص، مدیر (ادمین)
*   **توضیحات:** فرآیند مشاهده زمان‌های خالی، رزرو نوبت توسط مشتری، لغو نوبت و مشاهده برنامه کاری توسط متخصصین.
*   **شامل User Storyهای:** US-03, US-04, US-05, US-06, US-07, US-09

### UC-04: ثبت نظرات و امتیازدهی (Feedback System)
*   **Actor (بازیگر):** مشتری
*   **توضیحات:** ثبت نظر و امتیاز توسط مشتری برای متخصصین پس از پایان نوبت.
*   **شامل User Storyهای:** US-10 (نظرات و امتیازدهی)
