# 💅 سیستم خدمات و رزرو نوبت سالن زیبایی (Beauty Salon Booking System)

پروژه درس **مهندسی نرم‌افزار** - ترم ۱۴۰۴

## 📖 معرفی پروژه
این سیستم یک پلتفرم آنلاین برای مدیریت و رزرو نوبت در یک سالن زیبایی است. این پروژه به گونه‌ای طراحی شده تا مشتریان بتوانند به راحتی خدمات سالن را مشاهده کرده و در زمان‌های خالی نوبت رزرو کنند. همچنین مدیریت سالن می‌تواند نوبت‌ها و خدمات را از طریق پنل ادمین مدیریت کند.

## 🎯 چشم‌انداز و اهداف
- **مشتریان:** مشاهده لیست خدمات، بررسی قیمت‌ها و زمان‌بندی، و رزرو آنلاین نوبت.
- **مدیر سالن (ادمین):** مدیریت خدمات (افزودن/حذف)، مشاهده لیست نوبت‌های ثبت شده و مدیریت تقویم کاری.

## 👥 نقش‌های کاربری (Actors)
1. **مشتری (Customer):** مشاهده خدمات و رزرو نوبت.
2. **مدیر سیستم / ادمین (Admin):** مدیریت خدمات و نوبت‌ها.

## 🛠️ تکنولوژی‌های پیشنهادی
*(طبق تصمیم‌گیری تیم و مستندسازی در فایل معماری)*
- **Frontend:** React.js (یا Next.js)
- **Backend:** Node.js + Express
- **Database:** PostgreSQL
